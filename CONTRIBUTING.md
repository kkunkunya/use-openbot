# Contributing

Thanks for helping keep this skill accurate.

## Report a change in OpenBot

OpenBot moves fast. If a tool behaves differently from the skill, open an issue with:

- your OpenBot version (Settings → About),
- the provider your agent uses,
- the exact tool name and the message or error it returned.

## Send a pull request

- Keep `SKILL.md` short. It loads into the agent's context every time it triggers, so aim for under 120 lines.
- Write rules an agent can act on, and give the reason in a few words.
- Mark anything you tested with the OpenBot version you tested it on.
- Do not add personal data, company names, or absolute paths.
- Add a line to `CHANGELOG.md`.
